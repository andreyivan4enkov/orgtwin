# Контуры OrgTwin (продукт vs R&D)

## Продукт (продаём / демо)

| Факт | Как |
|---|---|
| Предсказание следующего шага | holdout next-step / top-3 / CE |
| Локальные правила, застревание | диагност |
| Очереди ×1/×2/слот | `queue_des` |
| Что если / каскад / оптимизатор L | API whatif / cascade / optimize |
| Мембраны prune | API membrane |
| Свой лог | upload CSV/XES |
| Greenfield | шаблоны + метка допущение |
| Σdt из DES | p50/p90 ожидание+сервис в очереди — **не** wall-clock ERP |
| Отчёт директору | HTML `/api/report/{id}` |

## R&D (не обещание без флага)

- FEP / case-head калибровка длительности
- Ridge(dt) как основной KPI
- Живой SAP / 1С / Битрикс (есть контракт `dry_run`)
- Полноценный SSO OIDC (пилот: `ORGTWIN_API_KEY`)

## Честная фраза для директора

«Мы предсказываем следующий шаг процесса и узкие места очереди по вашему следу событий; календарное время ERP и живые коннекторы — следующий этап после доступа к системам.»
