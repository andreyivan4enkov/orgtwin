# Арена — справка инструктора

## Сценарий

1. Донор BPIC2012 (или Hospital).
2. Найти узкое место на срезе ×2.
3. What-if: исключить / добавить слот / локальная нагрузка.
4. Цель: `peak_queue` сценария ≤ порога (по умолчанию 5) — `POST /api/arena/attempt`.

## Допуск

- `passed=true` → «допущен к пилоту клиента».
- Попытки: `data/derived/arena/attempt_*.json`.

## Без SSO

Оценка локальная. Для пилота у клиента включите `ORGTWIN_API_KEY`.
