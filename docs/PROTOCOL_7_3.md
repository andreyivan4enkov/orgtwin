# Протокол 7+3 / год фирмы ≤15

## Минимальный датасет клиента

1. Орг: до 15 FTE с ролями (или отделы как агенты).
2. Поток событий ≥ 12 месяцев: case, activity, timestamp, agent.
3. Стабильный case id на всём цикле.
4. PII замаскированы до передачи.

## Split

- Цель: **fit 7 мес + holdout 3 мес**.
- Если лог короче (как BPIC2012 ~5.5 мес) — UI/отчёт помечает урезанное окно; пропорция сохраняется.

## Валидация пайплайна

`GET /api/protocol/checklist` — чеклист приёмки.

Фикстура CI: `data/fixtures/synthetic_year_sme.csv` (синтетический год SME).

## Критерии «аэротруба v1 принята»

- next-step на holdout не случаен
- очередь ×2 растёт
- what-if / optimize воспроизводимы
- upload CSV/XES работает
- HTML-отчёт директору доступен
- greenfield с меткой «допущение»
