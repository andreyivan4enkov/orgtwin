# Виды структуры в OrgTwin (как в BI)

Ориентиры: Celonis PI Social / Network Explorer, pm4py org (handover), Power BI org / decomposition tree.

## Правило

**Иерархия и сеть не на одном холсте.** Смешение = «много линий, непонятно что значит».

| Вид | Вопрос | Аналог |
|-----|--------|--------|
| **Иерархия** | Кто в каком подразделении? | Org chart, decomposition tree |
| **Покрывало** | С кем связан *этот* сотрудник в работе? | Ego / handover neighborhood (не полный SNA) |

## Марковское покрывало здесь

Не полный граф компании. Вокруг выбранного сотрудника:

1. кто передаёт ему дела (входящий handover),
2. кому он передаёт (исходящий),
3. коллеги того же подразделения (мембрана роли).

Полный граф передач — режим **Поток**.
