# OrgTwin v0.10.0 — стресс очереди (BPIC2012)

**Контур:** simulator  
**Движок:** `queue_des` (capacity=1, FIFO, service time = `latency_sec`)  
**Дата:** 2026-09-03

## Протокол

- Split: 3+2 мес, holdout **5658** кейсов / **112847** событий
- Политика: softmax (маршрутизация), fit_acc **0.563**
- ×2 поток: дублирование кейсов на тех же arrival times (`input_flow_multiplier=2`)

## Результаты

|----------|-------------------------|-------------------|------|
| ×1 | **4236** | 85921 | 197 с |
| ×2 | **9905** | 173300 | 465 с |

Узкое место (агент `112`): 4236 → **9905** (+134%).

## Вывод

При удвоении входящего потока softmax продолжает раскидывать заявки, но **очереди перед узкими агентами растут на порядок** — это наблюдаемая метрика перегрузки, не «время в пути» из legacy batch-sim.

Полный JSON: `queue_stress_bpic2012.json`.

## Честные ограничения

- Нет календаря смен; FIFO без приоритетов.
- Service time = медиана из лога, не Ridge(dt).
- Агент `UNKNOWN` в топе — артефакт маппинга ролей BPIC2012.
