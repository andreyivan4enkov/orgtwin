## 2. Время отдельно от политики (`timing.py`) / 时间模块独立

| | RU | 中文 |
|--|----|------|
| Факт | `policy/timing.py`: Ridge(`log1p(dt)`) + case-level head; сима берёт dt после выбора Action | 选 Action 后再预测 dt |
| Факт из прогонов | Эмерджентная Σdt Spearman ≈ 0 (v0.3); калибровка dt→case-head — явный костыль (v0.4) | Σdt 涌现失败；校准是显式补丁 |
| Статус | Не закрыто: задержка не из шагов минимизации FEP | 未关闭：时延非 FEP 计算步结果 |

## 3. Python-циклы в FEP / 仿真 / FEP 与仿真循环

| | RU | 中文 |
|--|----|------|
| Факт | `fep.py`: EFE по действиям в Python-цикле; кэш по контексту | 按动作 Python 循环 + 上下文缓存 |

| Статус | Нет полной матричной векторизации EFE на весь батч живых кейсов | 未做全批次矩阵化 EFE |
